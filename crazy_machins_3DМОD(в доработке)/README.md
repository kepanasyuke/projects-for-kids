# ⚙ Мастерская Шестерёнкина — обучающая «Crazy Machines» игра

Интерактивный симулятор-головоломка для детей: 3D-сцены в стиле Crazy Machines + встроенный редактор кода. Ребёнок настраивает «регистры» (true/false, числа, строки-пароли), запускает механизм и смотрит, как шар, вода, вилка или шарик достигают цели.


## 🎯 Что это

8 «цехов» — 8 разных механизмов. В каждом нужно решить головоломку **через код**:

| Цех | Механика | Головоломка |
|-----|----------|-------------|
| 1 · Конвейер | Лесенка из 12 узлов | Открыть все барьеры (`true`) |
| 2 · Лампочка | Вилка падает в розетку | 220 В + замкнуть цепь |
| 3 · Стакан | Бак, кран, жёлоб, капли | Открыть кран + угол 15–35° |
| 4 · Ящик | Баллистический трамплин | Ловушка + датчик 4.2–4.7 |
| 5 · Сейф | Лимб и замочная скважина | Пароль-антоним + байпас |
| 6 · Шины | Вращающиеся валики | Скорость > 8 + снять канат |
| 7 · Пинг-понг | Каскад ракеток | Упругость 0.7–0.95 |
| 8 · Водопад | Два насоса + бассейн | Оба насоса + закрыть слив |

В каждом уровне 2–8 — **6–7 заданий-вопросов** прямо в коде (в комментариях) и **10 окон настройки**: часть вводится вручную (написать `220`, `true`, `"ОТКРЫТЬ"`), часть переключается кнопками.

## 🚀 Как запустить

Игра использует ES-модули (Three.js через importmap) — **просто открыть `index.html` двойным кликом не получится**, нужен локальный HTTP-сервер.

### Самый простой способ (GitHub Codespaces)

Откройте репозиторий в Codespaces и выполните:

```bash
make run
```

Откройте в браузере: **http://localhost:8000/** (или порт из `make port`).

### Всё через Makefile

| Команда | Что делает |
|---------|------------|
| `make setup` | Проверка окружения (python3 / node / npx) |
| `make run` | Запустить сервер на порту (по умолчанию 8000) |
| `make dev` | То же, что `make run` |
| `make port` | Показать номер порта и URL |
| `make kill-port` | Остановить процесс на порту |
| `make stop` | То же, что `make kill-port` |
| `make clean` | Удалить временные файлы (`node_modules`, кэш) |
| `make all` | Установка + запуск |

### Без Makefile (вручную)

**Вариант Python:**
```bash
python3 -m http.server 8000
# → http://localhost:8000
```

**Вариант Node (npx):**
```bash
npx --yes http-server . -p 8000 -c-1
# или
npx serve .
```

## 🕹 Как пользоваться

1. Введите имя юного инженера на титульном экране (имя запоминается).
2. Прочитайте задания в окне кода (зелёные комментарии перед настройками).
3. Заполните поля-регистры: числа впишите вручную, флаги переключите кнопкой.
4. Нажмите **«Запустить механизм»** — проверяются ключевые параметры.
5. Нажмите **«Проверить настройки»** — проверяются дополнительные (экспериментальные) параметры.
6. Победа — индикаторы зелёные, рекорд сохраняется в браузере (localStorage).

## 🧰 Технологии

- **Three.js r160** через importmap (CDN — нужен интернет при первом запуске)
- Пост-обработка: SSAO, Bloom, tone mapping
- Без сборки, без npm-зависимостей — один `index.html`
- Весь код игры — в единственном файле `index.html`
