# ASCII-проект: 16 заданий

Старый консольный проект сохранён отдельно и расширен до 28 заданий. Первые 16 заданий разделены на четыре Python-модуля по четыре сцены, дополнительные задания 17–28 находятся в отдельных тематических модулях.

```text
project_ascii/
├── module_1.py ... module_4.py   # задания 01–16
├── module_5.py ... module_16.py # задания 17–28
└── main.py      # меню всех заданий
```

## Запуск

```bash
python3 main.py
```

Для быстрой проверки без длинных пауз:

```bash
python3 main.py --fast
```

В каждом `module_*.py` есть блок между комментариями `НАЧАЛО КОДА УЧЕНИКА` и `КОНЕЦ КОДА УЧЕНИКА`. Замени заглушки `ВПИШИ_...` своими словами. Если оставить заглушку, выбранная ASCII-анимация покажет `GAME OVER` и подсказку.

## Группы заданий

- 01–04: списки ракет, планет, роботов и цветов;
- 05–08: множества продуктов, звёзд, кристаллов и звуков;
- 09–12: цепочки поезда, друзей, станций и нот;
- 13–16: словари героя, питомца, волшебника и космонавта;
- 17–28: животные, транспорт, погода, камни, спорт, музыка, сладости, профессии, планеты, путешествия, сад и будущее.

Проверка всех модулей:

```bash
make check
```
