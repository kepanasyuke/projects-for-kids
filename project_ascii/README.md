# Проект: ASCII-анимации структур данных

Это старый консольный проект. Он находится в папке `project_ascii` и содержит четыре учебные подпрограммы:

- `1_rockets.py` — список и ASCII-ракеты;
- `2_pizza.py` — множество и ASCII-пицца;
- `3_train.py` — связный список и ASCII-поезд;
- `4_hero.py` — словарь и ASCII-герой.

Общие функции находятся в `common.py`, меню — в `main.py`.

## Запуск

```bash
cd project_ascii
python3 main.py
```

Или отдельная сцена:

```bash
make rockets
make pizza
make train
make hero
make all
```

В каждом файле задания найди блок между комментариями `НАЧАЛО КОДА УЧЕНИКА` и `КОНЕЦ КОДА УЧЕНИКА`. Заглушки `ВПИШИ_...` нужно заменить своими данными. Если их не менять, сцена покажет подсказку и не запустит анимацию.

Проверка:

```bash
make check
```
