# 🎮 Шоу структур данных

Небольшой проект на чистом Python, в котором структуры данных оживают в терминале. Ракеты летят, пицца вращается, поезд едет, а герой появляется из портала.

Проект рассчитан на начинающих: у каждого задания есть свой файл и своё место для изменений.

## Что понадобится

- Python 3.10 или новее
- терминал
- желание экспериментировать

Сторонние библиотеки не нужны: используются только стандартные возможности Python.

## Быстрый старт

Открой терминал в папке проекта и выполни:

```bash
python3 main.py
```

Откроется меню. Введи номер сцены и нажми Enter.

Можно запускать сцены сразу по имени:

```bash
python3 main.py rockets
python3 main.py pizza
python3 main.py train
python3 main.py hero
python3 main.py all
```

То же самое через Makefile:

```bash
make help
make rockets
make pizza
make train
make hero
make all
```

Команда `make check` быстро проверяет код:

```bash
make check
```

## Где писать свой код

Открывай нужный файл и ищи две большие строки-комментария:

```python
# НАЧАЛО КОДА УЧЕНИКА
# ... сюда вставляем свои данные ...
# КОНЕЦ КОДА УЧЕНИКА
```

Писать нужно только между этими комментариями. Программа уже готова: она возьмёт твои данные и покажет их в анимации.

В начале каждого файла стоят заметные заглушки вроде `ВПИШИ_РАКЕТУ_1`. Это специально неправильные слова. Если оставить все заглушки как есть, программа не запустит анимацию, а покажет подсказку с примером. Сначала замени хотя бы данные задания, затем запускай сцену снова.

| Задание | Файл | Что менять |
| --- | --- | --- |
| Ракеты | `1_rockets.py` | `ROCKET_COLORS` — список названий |
| Пицца | `2_pizza.py` | `PIZZA_INGREDIENTS` — множество продуктов |
| Поезд | `3_train.py` | `TRAIN_CARS` и строку `insert` |
| Герой | `4_hero.py` | `HERO` — словарь характеристик |

Например, для задания про ракеты открой `1_rockets.py`, найди блок ученика и замени строку:

```python
ROCKET_COLORS = ["Молния", "Комета", "Звезда"]
```

Не вставляй этот код в `main.py`: `main.py` только показывает меню и запускает готовые части.

После каждого изменения сохрани файл, запусти нужную сцену, посмотри результат и попробуй следующий эксперимент.

## Задание 1: список и ракеты 🚀

```python
ROCKET_COLORS = ["Огненная", "Ледяная", "Космическая"]
```

Список (`list`) хранит элементы по порядку. Поэтому ракеты стартуют именно в том порядке, в котором записаны.

Попробуй:

1. заменить названия цветов на свои;
2. добавить четвёртую ракету;
3. поменять местами два цвета;
4. запустить `python3 main.py rockets` или `python3 1_rockets.py`.

Вопрос: какая ракета стартует первой после перестановки элементов?

## Задание 2: множество и пицца 🍕

```python
PIZZA_INGREDIENTS = {"сыр", "грибы", "кукуруза", "сыр"}
```

Множество (`set`) хранит только уникальные элементы. Слово `"сыр"` написано два раза, но в готовой пицце будет посчитано один раз.

Открой `2_pizza.py` и замени все четыре заглушки своими продуктами. Можно повторить один ингредиент, например написать `"сыр"` дважды, затем проверить количество уникальных продуктов.

Важно: у множества нет фиксированного порядка, поэтому ингредиенты могут появляться на экране в другой последовательности.

## Задание 3: связный список и поезд 🚂

```python
TRAIN_CARS = ["Паровоз", "Платформа", "Цистерна", "Тормозной"]
TRAIN_CARS.insert(2, "Вагон с динозаврами")
```

Функция `build_train` превращает названия в настоящую цепочку объектов `Car`:

```text
[Паровоз] -> [Платформа] -> [Вагон с динозаврами] -> [Цистерна] -> [Тормозной]
```

У каждого объекта есть поле `next` — ссылка на следующий вагон. Последний вагон ссылается на `None`.

В `3_train.py` измени название вагона, вставь `TRAIN_CARS.insert(1, "Мой вагон")` или поставь `insert(0, "Вагон впереди")`. Затем запусти `python3 main.py train`.

Вопрос: почему, чтобы добраться до четвёртого вагона, поезд должен пройти первые три?

## Задание 4: словарь и герой 🧙

```python
HERO = {
	"волосы": "Огненный ирокез",
	"глаза": "Лазерный прицел",
	"сила": "Невидимость",
	"оружие": "Гитара-бластер",
}
```

Словарь (`dict`) хранит пары «ключ: значение». По ключу `"сила"` программа находит значение `"Невидимость"`.

В `4_hero.py` измени характеристики, добавь ключ `"костюм"` и придумай значение:

```python
HERO["костюм"] = "Космический плащ"
```

Почему ключи нужно писать точно?

## Как устроен проект

```text
projects-for-kids/
├── main.py      # меню и общий запуск
├── common.py    # общие функции терминала
├── 1_rockets.py # задание 1: список
├── 2_pizza.py   # задание 2: множество
├── 3_train.py   # задание 3: связный список
├── 4_hero.py    # задание 4: словарь
├── Makefile     # короткие команды запуска
└── README.md    # эта инструкция
```

В каждом файле есть своя подпрограмма: `rockets_program`, `pizza_program`, `train_program` или `hero_program`. Файл `main.py` соединяет их в меню и в общий запуск `all`.

Флаг `--fast` отключает длинные паузы и удобен для проверки:

```bash
python3 main.py --fast all
```

## Финальный челлендж 🌟

Придумай три необычные ракеты, собери пиццу с пятью ингредиентами и одним повтором, добавь два вагона, создай героя с новой суперсилой и запусти `make all`.

После этого объясни своими словами:

- чем список отличается от множества;
- зачем связному списку поле `next`;
- почему словарь удобен для характеристик героя.

Главная идея: структура данных — это способ удобно хранить и находить информацию. А программирование превращает эту информацию в настоящее представление.
