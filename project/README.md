# Проект 1: JavaScript-анимации

Это отдельный браузерный проект. Все четыре задания написаны на JavaScript и лежат в собственных файлах:

- `1_rockets.js` — массив ракет;
- `2_pizza.js` — множество ингредиентов;
- `3_train.js` — связный список вагонов;
- `4_hero.js` — словарь характеристик героя.

`app.js` только соединяет задания с меню и Canvas-анимацией.

## Запуск

Из папки `project` запусти локальный сервер:

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000` в браузере. В Codespaces открой проброшенный порт 8000.

## Как выполнить задание

1. Нажми кнопку задания в браузере.
2. Открой соответствующий JS-файл.
3. Найди комментарии с `НАЧАЛО` и `КОНЕЦ` кода ученика.
4. Замени заглушки `ВПИШИ_...` своими данными.
5. Сохрани файл и обнови страницу.

Если заглушки не заменить, настоящая сцена не запускается. Вместо неё появляется отдельная анимация `GAME OVER` с подсказкой и примером.

Важный файл для изучения JS — `app.js`: там есть Canvas, игровой цикл `requestAnimationFrame`, переключение сцен, проверка заданий и запасная анимация ошибки.
