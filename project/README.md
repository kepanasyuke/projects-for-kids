# Проект 1: JavaScript-анимации

Это отдельный браузерный проект. Все 28 заданий написаны на JavaScript и разделены на 16 модулей: первые четыре модуля содержат по четыре задания, следующие 12 модулей — по одной дополнительной сцене.

- `module_1.js` — задания 01–04: базовые списки;
- `module_2.js` — задания 05–08: множества и коллекции;
- `module_3.js` — задания 09–12: цепочки и маршруты;
- `module_4.js` — задания 13–16: словари и персонажи;
- `module_5.js`–`module_16.js` — задания 17–28: новые тематические сцены.

`app.js` только соединяет задания с меню и Canvas-анимацией.

## Запуск

Из папки `project` запусти проект через Makefile:

```bash
make run
```

Перед запуском `make run` автоматически освобождает порт 8000, поэтому старый зависший сервер не мешает. Открой `http://localhost:8000` в браузере или проброшенный порт 8000 в Codespaces.

Полезные команды:

```bash
make kill-port  # остановить сервер на порту
make status     # проверить порт
make check      # проверить JavaScript
```

## Как выполнить задание

1. Нажми кнопку задания в браузере.
2. Открой соответствующий JS-файл.
3. Найди комментарии с `НАЧАЛО` и `КОНЕЦ` кода ученика.
4. Замени заглушки `ВПИШИ_...` своими данными.
5. Сохрани файл и обнови страницу.

Если заглушки не заменить, настоящая сцена не запускается. Вместо неё появляется отдельная анимация `GAME OVER` с подсказкой и примером.

В каждом модуле есть данные ученика, подсказка, пример и своя анимация. Важный файл для изучения JS — `app.js`: там есть Canvas, игровой цикл `requestAnimationFrame`, переключение 28 сцен, проверка заданий и запасная анимация ошибки.
